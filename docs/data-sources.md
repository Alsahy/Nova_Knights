# Where Mars Base Adventure's data comes from

*v1 · 13 Nov 2026 · for judges, teachers and curious grown-ups*

Mars Base Adventure is a fan-made educational game. It is **not affiliated with or endorsed by NASA**, and it uses public NASA data. Every fact shown in the game carries a source tag such as `[S6]`. The full list of 61 sources is in [`events-and-actions.md` §11](../events-and-actions.md) and on the in-game screen *"Where our data comes from"*.

## 2. M3 "Storm from the Sun": the real records

M3 is a **compressed storm replay** (decision D-009): real records with their real dates, sped up to fit 7 sols (D-043). The kid version (D-018) plays the flare and the particle storm; the Mars model run is kept below because it shows NASA predicting a cloud's arrival at Mars. The timeline is generated by `scripts/build-donki-timeline.ts` into `src/content/donki/m3-may2024.json`; every number below is computed from the snapshot.

| Game sol | Event | Real DONKI record | Real date | Game strength S | Label shown in the game |
|---|---|---|---|---|---|
| 2 | SW-01 Flash on the Sun! | FLR `2024-05-10T06:27:00-FLR-001` (class X3.9) | 2024-05-10 | 3 (X1–X4 → 3, spec §5) | "Real event: X3.9 flare on 2024-05-10 (NASA DONKI). It was seen from Earth; in this game we imagine it also reached your base." |
| 3 → 5 (played since D-026) | SW-03 Storm Cloud Coming → SW-04 The Storm Cloud Hits | WSA-ENLIL `WSA-ENLIL/30726/1` (Mars arrival 2024-05-13T17:42Z, not a glancing blow; CME ≈ 1,263 km/s) | model run 2024-05-11 | 3 (base 2, +1 because the CME was faster than 1,000 km/s) · warning 2 sols | "NASA's model predicted this cloud would reach Mars on 2024-05-13." |
| 6 | SW-02 Radiation Storm! | SEP `2024-05-13T14:00:00-SEP-001` (GOES >10 MeV, linked to an M6.6 flare) | 2024-05-13 | 2 (linked flare's S, minimum 2) | "Real event: a solar particle storm on 2024-05-13 (NASA DONKI, after an M6.6 flare). It was measured near Earth; in this game we imagine it also reached your base." |

Each card also says **"Replay, sped up · ARCHIVED – fetched on 2026-11-13"** and links to the record on the DONKI website. Nothing in the game is called "live".

**Note on 20 May 2024.** Curiosity's biggest radiation surge came from a far-side eruption on 20 May 2024 [S6]. DONKI lists it only as a CME (`2024-05-20T05:36:00-CME-001`, ≈ 1,927 km/s); it has no particle-event record and no model run with a Mars arrival for it. So the game quotes that surge as a fact in SW-02's science text and uses the 13 May particle event for the playable beat.

## 3. Honesty table: real → game

Slow processes run **15× faster** in the game (radiation adding up, plants growing) so kids can see them in a short mission. Ratios stay real. Numbers on cards are **game values**, not measurements.

| Real fact | Game value | Source |
|---|---|---|
| Career limit 600 mSv | Badge full at 10 (1 pip ≈ 60 mSv) | [S9] |
| One solar particle event limit 250 mSv | Worst storm = +4 | [S9] |
| Surface ≈ 0.64 mSv/day | +1 badge every 6 sols (every 12 behind a thick shield) | [S8] |
| May 2024 surge ≈ 8 mGy (8,100 µGy) | Big storm = +2 to +4 **(game-exaggerated)** | [S6][S9] |
| Sunlight 586 vs 1,361 W/m² | Solar 4 power on a clear sol | [S13] |
| Opportunity −97 % at tau 10.8 | Dust multipliers ×0.6 / ×0.3 / ×0.05 | [S15][S16] |
| Water recovery 93–94 % → 98 % | 4 crew lose 1 water every 4 sols → every 12 | [S27] |
| ~0.8 kg O₂ per person per day from water | Oxygen maker uses 1 water per sol (game-simplified) | [S21][S28] |
| 3,035 kcal and ≥ 2.5 L per day | 1 food and 1 water per astronaut per sol | [S20] |
| Lettuce 33 days, peppers 137 days | Lettuce 2 sols, peppers 9 sols | [S33][S34] |
| Signal delay 4–20 min each way | "Ask Earth" answers arrive after the current event | [S54] |

The storm label shown in the game (decision D-008): *"Storms are made bigger in the game so shields matter. The real May 2024 storm at Mars was about 8 mGy, like 30 chest X-rays [S6]. The game's worst storm (+4) is close to NASA's 250 mSv single-event limit [S9]."*

## 4. Source audit (13 Nov 2026)

We opened every source used by the 37 playable events and the honesty table (43 sources) and checked that the page contains the figure we quote.

- **37 verified** (the quoted figures are on the page).
- **5 need a fix** (proposal P-008, waiting for the team lead): S2 (host unreachable; the M3 ENLIL record shows the same thing), S6 (news re-post; the NASA JPL original has the same figures), S16 (the 468 Wh figure is no longer on the page), S23 (link now lands on an index page; S24 covers the same Apollo 13 story), S25 (link now redirects to a home page).
- **3 not checkable automatically** (the sites block scripts): S26, S42, S55. A person will check them in a browser.

Source tags are never removed to save space; a fact with no working source does not ship.

## 5. What is NOT real data

- The base, crew, cards and all game numbers are a game model built on the facts above.
- The cockpit background is an AI-generated illustration, not a NASA image.
- Mission M1 uses a calm Sun on purpose (it's the tutorial).
